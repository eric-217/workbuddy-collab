# WorkBuddy 协作中枢

> 财富管理项目跨对话协作数据仓库

## 这是什么？

这里存放所有对话公用的协作数据：

| 文件类型 | 作用 |
|----------|------|
| `MEMORY_SYNC.md` | 本地记忆备份，防止压缩丢失 |
| `协作规则_*.md` | 各主题的工作约定和分析方法 |
| `ISSUES_*.md` | 跨对话待办事项追踪 |
| `跨对话启动命令.md` | 新对话启动时发给 AI 的命令 |

## 如何使用

### AI 对话启动
每个新对话开始时，AI 会自动：
1. `git pull` 拉取最新协作数据
2. 读取对应主题的 ISSUES 和协作规则
3. 汇报待办事项

### 手机端操作
- 浏览器打开 GitHub 仓库
- 直接编辑 ISSUES 文件添加想法
- 下次对话 AI 自动获取
